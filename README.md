Refer article: https://learnopengl.com/Lighting/Lighting-maps
Since the real world object consist of different materials and these materail have different response to light.
We have added diffusion and specular maps in our fragment shader.
We are using a wooden texture with steel boundary. By introducivng diffusion and specular map
the container's material now closely resembles that of an actual wooden container with steel frames
Later on we add emission map to make our object emmit light (eg. robot eyes)
